API documentation

The linkding HTTP API exposes CRUD operations for bookmarks, tags, bundles and start page objects (pages, widgets, smart links). All endpoints share the same token auth scheme, so a single API token unlocks the whole API.

Authentication

Create a token from Settings → Integrations and pass it in the Authorization header: 

Authorization: Token <your-token>

Bearer is accepted as an alias.

Browse

  • Swagger UI — interactive explorer for every endpoint
  • Redoc — reference-style reading view
  • OpenAPI schema (YAML) — raw spec, feed it to your agent / codegen
  • Curl cheatsheet (markdown) — quickstart with copy-paste curl commands

Start page preview as markdown

Every start page exposes a read-only markdown snapshot at /start/api/pages/<id>/preview/ when you send Accept: text/markdown. Paste it into an agent context to brief them on the current state of a page.
